# Discord Archiver v1.0.0

The first public release saves your own Discord direct messages, group chats, and shared files for offline browsing.

## Included

- A graphical window for selecting and exporting conversations.
- Native downloads for Windows, macOS, and Linux, plus a source ZIP for Python users.
- Offline HTML conversations and readable transcripts.
- Resumable exports, missing-file retries, and refreshed edited messages.
- File-format correction and content-based deduplication.
- Optional terminal commands for export, search, and local browsing.

Download the package matching your operating system and processor, extract it, and read the README before starting. Native downloads include Python. Source users need Python 3.10 or newer and Tkinter for the window.
